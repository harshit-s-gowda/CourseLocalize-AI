# PROJECT: AI-Powered Multilingual Content Localization Engine for Skill Courses

Act as a senior full-stack developer, AI/ML engineer, UI/UX designer, and software tester. Build a complete, user-friendly, working prototype for my college Design Project-I.

## 1. Project Objective

Build a web application that translates English technical course content into Indian languages while preserving technical terminology, programming code, headings, lists, and educational structure.

Target languages:
- Kannada
- Hindi
- Tamil
- Telugu

The application must be functional, easy for students to use, and suitable for a live college project demonstration.

## 2. Technology Stack

Use the following stack:

- Frontend: Streamlit
- Programming language: Python
- Translation model: AI4Bharat IndicTrans2
- Model integration: Hugging Face and the official IndicTrans2 inference instructions
- Text processing: Python and regular expressions
- PDF processing: PyMuPDF or an equivalent Python PDF extraction library
- Storage: JSON or local files for the initial prototype
- Version control: Git and GitHub
- Evaluation: BLEU and chrF++ where appropriate

Keep the application simple enough to run on a student laptop. Do not require MongoDB, paid APIs, or model training for the initial version.

## 4. Core Localization Pipeline

Implement the following workflow:

Step 1: Accept course text from a file upload or text input.

Step 2: Validate the input and reject empty or unsupported files.

Step 3: Extract the text and identify headings, paragraphs, lists, tables where supported, and code blocks.

Step 4: Identify technical terms using a configurable terminology dictionary.

Step 5: Protect programming code and other content that must remain unchanged by replacing it with unique placeholders.

Step 6: Translate the remaining text using IndicTrans2 into the selected target language.

Step 7: Restore the original code and protected content exactly.

Step 8: Reconstruct the original course structure as closely as possible.

Step 9: Run checks for missing placeholders, code changes, empty output, and structural inconsistencies.

Step 10: Display the translated content and allow the user to download it.

Do not translate the protected placeholders themselves. If a placeholder is missing or corrupted, report the problem rather than silently producing an incorrect result.

## 5. Translation Model Integration

Use the official AI4Bharat IndicTrans2 model and its documented inference process.

- Support English-to-Kannada, English-to-Hindi, English-to-Tamil, and English-to-Telugu.
- Use the appropriate model and language codes from the official documentation.
- Process long content in manageable chunks.
- Preserve paragraph order when combining translated chunks.
- Handle model-loading errors, missing dependencies, and unsupported inputs.
- Provide installation instructions for the required model dependencies.
- Do not train a new model from scratch.

If the model cannot run in the current environment, explain the exact reason and provide a configurable, documented alternative inference endpoint. Do not silently substitute random, hardcoded, or fake translations.
