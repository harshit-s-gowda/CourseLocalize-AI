# Python functions and variables

A function is a reusable block of instructions. A variable stores a value that a
program can use later. A clear function name helps readers understand what the
program does.

## Example

The following Python function adds two values and returns the result.

```python
def add_numbers(first_value, second_value):
    result = first_value + second_value
    return result
```

- `add_numbers` is the function name.
- `first_value` and `second_value` are variables.
- The code block should remain unchanged during localization.

| Term | Meaning |
| --- | --- |
| Function | Reusable instructions |
| Variable | A named value |
